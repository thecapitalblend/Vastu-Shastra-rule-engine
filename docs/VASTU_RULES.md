# Vastu Rule Source Discipline

Rules are classified as a reference framework, not automatically as exact verse-level prescriptions.

Recommended hierarchy:
1. Verified primary text + edition + chapter/verse/page.
2. Scholarly translation/commentary.
3. Traditional practice.
4. Modern interpretation.

Do not represent levels 3–4 as exact ancient rules. Building code, structural engineering, fire safety, accessibility, services and local development regulations remain mandatory.
