# Vastu Shastra reference framework

## 1. Mānasāra
Prasanna Kumar Acharya, *Architecture of Mānasāra: Text with English Translation and Notes*.
The text is a major Sanskrit architectural treatise covering site, architecture, measurement/proportion and related subjects. Use the exact edition/chapter when converting a Sanskrit prescription into a software rule.

## 2. Mayamata
Bruno Dagens, *Mayamata: An Indian Treatise on Housing Architecture and Iconography* (Motilal Banarsidass, 1985 English edition). The classical work covers site selection, orientation/layout, architectural elements, houses and other building types.

## 3. Viśvakarma Vāstu Śāstram
Government of India / Sanskrit archive material is included as a supplementary primary-source lead. The archive introduction describes Vastu as a science of habitations and distinguishes ground, mansion, vehicle and bedstead.

## Rule implementation principle
1. Every automated rule gets a stable ID.
2. Every rule gets a source field.
3. Classical-text rules are not mixed with modern internet/practitioner rules.
4. If two traditions conflict, the engine reports the conflict.
5. Exact shloka/page/edition should be added before claiming a rule is a verbatim textual prescription.
6. Vastu does not replace structural engineering, NBC/local bye-laws, fire safety, accessibility, energy, plumbing, drainage or approval requirements.
