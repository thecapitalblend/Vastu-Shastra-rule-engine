# Senior architecture workflow

1. Capture survey inputs: plot dimensions, road side, true north, setbacks, levels, soil/geotechnical data and local bye-laws.
2. Establish Vastu grid and orientation as a design constraint, not as a replacement for engineering.
3. Build room program and adjacency matrix.
4. Generate 2D options with real dimensions.
5. Run Vastu rule engine and show PASS / REVIEW / CONFLICT with source IDs.
6. Check daylight, ventilation, circulation, parking, plumbing stacks and structure.
7. Generate 3D massing and facade options.
8. Generate interior and exterior AI concepts only after the geometry is fixed.
9. Export DXF/PDF/PNG/OBJ.
10. Finalize construction drawings only after architect/structural engineer review and local approval checks.
